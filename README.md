# ML Logistics website

Repository: `mllogistics.ng-website`

Brand: **ML Logistics**
Formal identity: **ML Logistics Nig. — A subsidiary of ML Enterprise**

Main service line: **Delivery, Dispatch & Moving Services**

## Deployment
GitHub Pages is configured to deploy from `main` / root.

## CMS
`.pages.yml` is a Git-based CMS configuration for Pages CMS. The CMS edits content stored in this GitHub repository; GitHub remains the source of truth.

## Important
The website currently has no payment gateway, live vehicle API, customer database or automated tracking database. The Tracking page therefore directs users to support for current status rather than pretending to provide live tracking.
